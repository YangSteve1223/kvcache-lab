# 实验14: Baseline对比实验

## 实验配置

- **模型**: 32层
- **请求数**: 200个/场景
- **任务混合**: math 25%, code 25%, qa 25%, conversation 25%
- **输入Token**: 500-6000
- **输出Token**: 100-1500
- **运行次数**: 3次 (取平均)

## 对比策略

1. **None**: 无压缩
2. **Uniform**: 均匀压缩50%保留率
3. **KVServe**: 贝叶斯Pareto搜索最优均匀压缩
4. **PDTrim**: 首尾保留80%+中间层剪枝30-50%
5. **PD-Aware**: P/D差异化压缩
6. **Task-Aware**: 任务感知压缩
7. **PD-Task-Aware**: 联合策略

## 分析与结论

### 关键发现

- **1GB/s**: TTFT最优=Uniform(107ms), 质量最优=None(1)
- **5GB/s**: TTFT最优=PD-Aware(86.46ms), 质量最优=None(1)
- **50GB/s**: TTFT最优=Task-Aware(81.67ms), 质量最优=None(1)

### 策略特性分析

- **None**: 质量最高(1.0)，无压缩，无带宽节省。适合带宽充足场景。
- **Uniform**: 简单均匀压缩，质量约0.5。
- **KVServe**: Pareto优化，在满足SLO的前提下最大化质量。
- **PDTrim**: 首尾保留策略，中间层激进剪枝。代码任务效果较好。
- **PD-Aware**: P/D差异化，平衡延迟和质量。
- **Task-Aware**: 任务自适应，数学/QA保持高层，代码保持低层。
- **PD-Task-Aware**: 联合策略，综合P/D和任务感知优势。

### 建议

- **带宽受限(1GB/s)**: 推荐 PD-Aware 或 PD-Task-Aware
- **中等带宽(5GB/s)**: 推荐 KVServe 或 PD-Task-Aware
- **带宽充足(50GB/s)**: 推荐 None 或 PD-Aware（保守压缩）
- **质量优先**: 推荐 PD-Task-Aware 或 PD-Aware
- **任务敏感**: 推荐 Task-Aware 或 PD-Task-Aware
