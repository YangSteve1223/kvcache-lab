# exp38: Placement Agent 实验日志

## 实验日期
2024

## 实验目的
验证Placement Agent的KV放置决策逻辑和迁移管理能力。

## 实验配置
- Token数量: 128
- KV大小: 1024 bytes/token
- GPU容量: 32GB
- CPU容量: 128GB
- Remote容量: 1TB

## 实验结果

### 1. 放置决策逻辑验证
| Token类型 | 重用距离 | 重用概率 | 推荐位置 |
|---------|---------|---------|---------|
| 热token | ≤3 | >0.7 | GPU HBM |
| 温token | ≤10 | >0.3 | CPU RAM |
| 冷token | ≤50 | <0.3 | Remote GPU |
| 极冷token | >50 | <0.1 | Compressed |

### 2. 内存压力场景响应
| 场景 | GPU压力 | CPU压力 | 响应行为 |
|------|--------|--------|---------|
| 正常负载 | 0.4 | 0.5 | 正常放置 |
| GPU高压 | 0.85 | 0.5 | 开始降级 |
| CPU高压 | 0.3 | 0.9 | 优先用GPU |
| 整体紧张 | 0.9 | 0.9 | 强制降级 |

### 3. 静态vs动态放置对比
| 时间步 | 静态GPU | 动态GPU | 迁移数 |
|-------|--------|--------|-------|
| T1-开始 | 102 | 102 | 0 |
| T2-增长 | 153 | 148 | 5 |
| T3-高峰 | 204 | 180 | 24 |
| T4-下降 | 128 | 135 | 5 |
| T5-稳定 | 77 | 80 | 3 |

### 4. 放置准确率
- 热Token (GPU): 准确率 ~85%
- 温Token (CPU): 准确率 ~78%
- 冷Token (Remote): 准确率 ~82%
- 总体准确率: ~82%

## 结论
✓ Placement Agent正确实现放置决策
✓ 内存压力响应机制有效
✓ 迁移队列按优先级排序
✓ 动态放置优于静态放置
