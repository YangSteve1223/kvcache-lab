## 4. RDKV局限性分析

### RDKV未考虑的问题

| 问题 | RDKV | 本框架 |
|------|------|--------|
| PD分离传输 | ❌ 单节点 | ✅ P/D差异化 |
| 传输带宽约束 | ❌ 无 | ✅ bytes/ms约束 |
| SLO延迟约束 | ❌ 无 | ✅ ms级约束 |
| Semantic失真 | ❌ Attention失真 | ✅ 生成质量 |
| Phase-aware β | ❌ 无 | ✅ β_P ≠ β_D |
| Unequal Error Protection | 基础 | ✅ IB重要性加权 |
